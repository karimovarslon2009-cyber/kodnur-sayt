Python bilan tanishuv

Python — dunyodagi eng sevimli dasturlash tillaridan biri. Telegram-botlar, o'yinlar, sun'iy intellekt, sayt va do'konlar — hammasi Python bilan yoziladi. Bu darsda birinchi dasturingizni yozasiz: print() bilan ekranga matn chiqarishni, izoh yozishni va xato xabarini o'qishni o'rganasiz.

⏱ ~3 soat🎯 print, sep, end, izohlar, \n va \t🧩 20 topshiriq + mini-loyiha
40 daq nazariya100 daq 20 ta topshiriq30 daq mini-loyiha10 daq test

Darsning maqsadi

1
Python nima — dastur qanday yoziladi va qanday ishlaydi, Python qayerda ishlatiladi.
2
print() funksiyasi — matn va sonlarni ekranga chiqarish, bir nechta qiymatni bitta print bilan chiqarish.
3
sep va end — chiqarilgan qiymatlar orasidagi belgini va qator oxirini o'zingiz tanlash.
4
Maxsus belgilar — \n (yangi qator), \t (tabulyatsiya) va qo'shtirnoqlarni matn ichida yozish.
5
Izohlar va xatolar — # bilan izoh yozish; SyntaxError va NameError xabarini o'qib, xatoni tuzatish.

Bugungi yangi sintaksis

print("matn")print(a, b, sep="-")print("...", end="")\n \t# izoh

Bu sahifa qanday ishlaydi

Kod oynalari — jonli. Python shu sahifaning ichida ishlaydi, hech narsa o'rnatish shart emas:
  • Kodni yozing va ▶ Ishga tushir (yoki Ctrl + Enter) bosing. Natija pastdagi Terminalda chiqadi.
  • Dastur input() so'rasa, terminalda yozish maydoni chiqadi: javobingizni yozib Enter bosing.
  • Xato bo'lsa, terminalda xato qatori va tushuntirish chiqadi. Xato topilgan qator oynada qizil bo'ladi.
  • ✔ Tekshirish tugmasi dasturingizni bir necha xil ma'lumot bilan sinab, har bir talabni alohida ✅ yoki ❌ bilan ko'rsatadi.
  • Topshiriqlar ketma-ket ochiladi. Yechim 10 ta muvaffaqiyatsiz urinishdan keyin ko'rinadi. 💡 Yordam 3 bosqichli.
  • Birinchi marta Python yuklanadi (bir necha soniya). Yozgan kodingiz brauzerda saqlanadi.

Maxsus belgilar: \n, \t va qo'shtirnoq

  1. Matnni boshqa turdagi tirnoq bilan o'rang: 'Men "Python" ni yaxshi ko'raman' — lekin bunda ichidagi apostrof muammo bo'ladi.
  2. Ichidagi tirnoq oldiga \ qo'ying.

Mini-test (8 ta savol)

1. Qaysi yozuv ekranga Salom matnini to'g'ri chiqaradi?
Matn qo'shtirnoq ichida bo'ladi, funksiya nomi esa kichik harfda: print("Salom").
2. print("2 + 3") nima chiqaradi?
Qo'shtirnoq ichidagi narsa matn. Python uni hisoblamaydi, aynan shunday chiqaradi.
3. print("A", "B", sep="-") nima chiqaradi?
sep qiymatlar orasiga qo'yiladigan belgini belgilaydi. Bu yerda u chiziqcha.
4. print("Salom", end="!") dan keyingi print qayerdan chiqaradi?
end qator oxiriga nima qo'yilishini belgilaydi. Yangi qator o'rniga ! qo'yilgani uchun keyingi chiqish shu qatorda davom etadi.
5. \n belgisi nima qiladi?
\n (new line) matn ichida yangi qatorga o'tishni bildiradi.
6. Python izohi qanday boshlanadi?
Python'da izoh # belgisi bilan boshlanadi. # dan keyingi qator oxirigacha Python o'qimaydi.
7. Print("Salom") qanday xato beradi?
Python katta-kichik harfni farqlaydi. Print degan nom yo'q, shuning uchun NameError chiqadi.
8. print("Salom) qatorining xatosi nimada?
Matn qo'shtirnoq bilan boshlangan, lekin qo'shtirnoq bilan tugamagan. Natija: SyntaxError.
