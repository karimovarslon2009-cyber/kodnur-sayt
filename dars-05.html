Shartlar

Hozirgacha dasturlaringiz har doim bir xil yo'ldan yurardi: yuqoridan pastga, hamma qatorni bajarib. Bugun ular qaror qabul qilishni o'rganadi. Svetofor yashil bo'lsa — yur, qizil bo'lsa — to'xta. Bu darsda if, elif, else, mantiqiy amallar va match bilan shunday "aqlli" dasturlar yozasiz.

⏱ ~3 soat🎯 taqqoslash, if/elif/else, and/or/not, a if shart else b, match/case, rost va yolg'on qiymatlar🧩 20 topshiriq + mini-loyiha
40 daq nazariya100 daq 20 ta topshiriq30 daq mini-loyiha10 daq test

Darsning maqsadi

1
Taqqoslash — ==, !=, <, >, <=, >= amallari va ularning natijasi True yoki False.
2
if, elif, else — shartga qarab turli kodni bajarish; chekinish (indent) va shartlar tartibi nega muhimligi.
3
and, or, not — bir nechta shartni birlashtirish va shartni teskarisiga aylantirish.
4
Ichma-ich shart va qisqa ifoda — if ichida if; bitta qatorli a if shart else b.
5
match/case — bitta qiymatni ko'p variant bilan solishtirishning qulay usuli.
6
Rost va yolg'on qiymatlar — 0, "", None nega "yolg'on", "0" esa nega "rost".

  3. D > 0 bo'lsa ikki ildiz: x1 = (-b + √D) / (2a), x2 = (-b - √D) / (2a). Ularni x1 = 3.00, x2 = 2.00 ko'rinishida chiqaring.
  4. D == 0 bo'lsa bitta ildiz: x = -b / (2a) → x = -1.00.
  5. D < 0 bo'lsa: Haqiqiy ildiz yo'q.
  6. Ildizlar 2 xona aniqlikda: f"{x1:.2f}". Ildiz uchun math.sqrt() yoki ** 0.5 ishlating.
✅ Natija shunday chiqishi kerak: 1, -5, 6 →
D = 1
x1 = 3.00
x2 = 2.00
1, 2, 1 → D = 0 va x = -1.00; 1, 1, 5 → D = -19 va Haqiqiy ildiz yo'q.
