Modullar va standart kutubxona

Python bilan birga yuzlab tayyor modullar keladi: tasodifiy sonlar, matematika, sanalar, sanash, kombinatsiyalar. Ularni qayta yozish shart emas, faqat import qilasiz. Bu darsda tayyor modullardan foydalanishni, o'z modulingizni yozishni va if __name__ == "__main__": nima uchun kerakligini o'rganasiz.

Modul nima va import qanday ishlaydi

💡 Asosiy fikr: Modul — tayyor funksiyalar yozilgan Python fayli. import uni dasturingizga ulaydi, shunda uning funksiyalarini ishlatasiz.

🔹 Kutubxonadagi kabi

Maktab kutubxonasida har fanga alohida kitob bor. Matematika kerak bo'lsa, matematika kitobini olasiz. Python'da ham shunday: standart kutubxona (standard library) — Python bilan birga keladigan modullar to'plami. Kerakli modulni import bilan "olasiz".

O'z modulingiz va if __name__ == "__main__"

💡 Asosiy fikr: Har qanday .py fayl — modul. Funksiyalaringizni alohida faylga yozib, boshqa fayldan import qilasiz.

🔹 Ikki fayl

Dastur kattalashsa, hamma narsani bitta faylga yozish noqulay. Funksiyalarni mavzu bo'yicha alohida fayllarga ajratasiz. Masalan, hisob.py faylida hisob-kitob funksiyalari:

# hisob.py
def ortacha(sonlar):
    return sum(sonlar) / len(sonlar)


def eng_katta(sonlar):
    return max(sonlar)

Shu papkadagi main.py faylida uni ishlatasiz. Modul nomi — fayl nomi, faqat .py siz.

# main.py
import hisob

baholar = [5, 4, 3, 5]
print(hisob.ortacha(baholar))   # 4.25
print(hisob.eng_katta(baholar)) # 5
📁 Muhim: ikkala fayl bitta papkada bo'lishi kerak. Python modulni avval dastur turgan papkadan, keyin standart kutubxonadan qidiradi.

🔹 __name__ nima?

Har bir faylda Python o'zi yaratadigan __name__ o'zgaruvchisi bor. Fayl to'g'ridan-to'g'ri ishga tushirilsa, uning qiymati "__main__" bo'ladi. Fayl import qilinsa, qiymati fayl nomi bo'ladi (masalan, "hisob").

📄 main.py

🔹 if __name__ == "__main__":

Modul ichida sinov uchun print yozdingiz, deylik. Uni import qilganingizda o'sha print ham ishlab ketadi. Buning oldini olish uchun sinov kodini shu shart ichiga yozasiz:

# hisob.py
def ortacha(sonlar):
    return sum(sonlar) / len(sonlar)


if __name__ == "__main__":
    # faqat "python hisob.py" deb ishga tushirilganda ishlaydi
    print(ortacha([2, 4]))

pip va venv: tashqi kutubxonalar

💡 Asosiy fikr: Standart kutubxonada yo'q narsalarni dunyo dasturchilari yozgan tashqi kutubxonalardan olasiz. Ularni pip o'rnatadi, venv esa har loyihaga alohida "quti" yaratadi.

🔹 pip — kutubxona o'rnatuvchi

PyPI (pypi.org) saytida 500 mingdan ortiq kutubxona bor: requests (internet), pandas (jadvallar), django (saytlar). Ular kompyuteringizdagi terminalda o'rnatiladi:

pip install requests        # o'rnatish
pip install requests==2.32.3  # aniq versiya
pip list                    # nimalar o'rnatilgan
pip uninstall requests      # o'chirish
pip freeze > requirements.txt  # loyiha kutubxonalari ro'yxati
pip install -r requirements.txt # ro'yxat bo'yicha o'rnatish

🔹 venv — virtual muhit

Bitta loyihaga kutubxonaning eski versiyasi, boshqasiga yangisi kerak bo'lishi mumkin. Virtual muhit har bir loyihaning kutubxonalarini alohida papkada saqlaydi. Har o'quvchining o'z portfeli bo'lgani kabi.

python -m venv .venv          # muhit yaratish
.venv\Scripts\activate        # Windows: yoqish
source .venv/bin/activate     # macOS / Linux: yoqish
pip install requests          # endi faqat shu loyihaga o'rnatiladi
deactivate                    # o'chirish
🌐 Bizning kurs sahifasida Python brauzer ichida ishlaydi, shuning uchun pip install bu yerda kerak emas. Standart kutubxona to'liq ishlaydi. pip va venv ni o'z kompyuteringizda, VS Code terminalida sinab ko'rasiz.
Real loyihada: har bir jiddiy loyihada .venv papkasi va requirements.txt fayli bo'ladi. Siz Django'da ham shunday qilgansiz.
