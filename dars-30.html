Tashqi dunyo bilan aloqa: requests va API

Ob-havo ilovasi, valyuta kurslari, onlayn do'kon — ularning hammasi ma'lumotni serverdan oladi. Dastur serverga so'rov yuboradi, server javob qaytaradi — odatda JSON ko'rinishida. Bu darsda requests kutubxonasi bilan xuddi shunday qilamiz. Muhim: brauzerda haqiqiy internetga chiqib bo'lmaydi, shuning uchun darsda o'quv API (https://api.xorazm-market.uz) ishlaydi. Kod esa haqiqiy requests kodi bilan bir xil yoziladi — kompyuteringizda faqat manzilni almashtirasiz.

⏱ ~3 soat🎯 GET/POST, holat kodlari, JSON, params, timeout, kesh, qayta urinish🧩 20 topshiriq + mini-loyiha
40 daq nazariya100 daq 20 ta topshiriq30 daq mini-loyiha10 daq test

Darsning maqsadi

1
HTTP asoslari — so'rov, javob, GET va POST, holat kodlari (200, 404, 500).
2
requests — requests.get(), .json(), .status_code, raise_for_status().
3
Parametrlar — params= bilan qidirish, json= bilan yuborish.
4
Xatolarga chidamlilik — timeout, try/except, qayta urinish.
5
Xavfsizlik — API kalitini kod ichida emas, muhit o'zgaruvchisida saqlash.
6
Kesh — bir xil so'rovni takror yubormaslik.

Bugungi yangi sintaksis

r = requests.get(URL, timeout=5)r.raise_for_status()data = r.json()requests.get(URL, params={"kategoriya": "maktab"})requests.post(URL, json={"mahsulot_id": 1, "soni": 2})except requests.exceptions.Timeout:os.environ.get("API_KALIT")

Bu sahifa qanday ishlaydi

Kod oynalari — jonli. Python shu sahifaning ichida ishlaydi, hech narsa o'rnatish shart emas:
  • Kodni yozing va ▶ Ishga tushir (yoki Ctrl + Enter) bosing. Natija pastdagi Terminalda chiqadi.
  • Dastur input() so'rasa, terminalda yozish maydoni chiqadi: javobingizni yozib Enter bosing.
  • Xato bo'lsa, terminalda xato qatori va tushuntirish chiqadi. Xato topilgan qator oynada qizil bo'ladi.
  • ✔ Tekshirish tugmasi dasturingizni bir necha xil ma'lumot bilan sinab, har bir talabni alohida ✅ yoki ❌ bilan ko'rsatadi.
  • Topshiriqlar ketma-ket ochiladi. Yechim 10 ta muvaffaqiyatsiz urinishdan keyin ko'rinadi. 💡 Yordam 3 bosqichli.
  • Birinchi marta Python yuklanadi (bir necha soniya). Yozgan kodingiz brauzerda saqlanadi.

So'rov, javob va holat kodlari

💡 Asosiy fikr: HTTP — so'rov-javob qoidasi. Siz manzil (URL) va usul (GET/POST) bilan so'rov yuborasiz, server holat kodi va ma'lumot qaytaradi.
ℹ️ O'quv APIBu yerda https://api.xorazm-market.uz — kursimiz ichidagi o'quv serveri, haqiqiy internet emas. Undagi mahsulotlar, ob-havo va kurslar tayyorlab qo'yilgan. Boshqa saytga so'rov yuborsangiz ConnectionError chiqadi. Haqiqiy kompyuteringizda requests aynan shunday ishlaydi.

Xatolar, timeout, qayta urinish

💡 Asosiy fikr: Tarmoq ishonchsiz: server javob bermasligi, uzilishi, xato qaytarishi mumkin. Har so'rovga timeout bering va xatolarni ushlang.
📄 main.py

🔹 Qayta urinish

Vaqtinchalik xatolarda (timeout, 500) so'rovni 2–3 marta takrorlash mumkin. Har urinish orasida kutish qo'shiladi (haqiqiy kodda time.sleep):

for urinish in range(1, 4):
    try:
        r = requests.get(URL, timeout=2)
        r.raise_for_status()
        break                       # muvaffaqiyat
    except requests.RequestException:
        if urinish == 3:
            raise                   # oxirgi urinish ham o'xshamadi
        time.sleep(urinish)         # 1, 2 soniya kutish

🔹 Kesh va API kaliti

  • Kesh: bir xil so'rov natijasini lug'atda saqlang — takror so'rov kerak emas (tezroq, arzonroq).
  • API kaliti — parol kabi. Uni kodga yozmang (kod GitHub ga chiqib ketishi mumkin). os.environ.get("API_KALIT") orqali oling.

💡 Asosiy fikr: Tarmoq bilan ishlaganda "ishlayapti" yetarli emas: server sekin, ishlamay qolgan yoki kutilmagan javob qaytargan hollar uchun ham tayyor bo'lish kerak.
⚠️ Holatni tekshirmay json()404 javobning JSON i boshqa tuzilmada. Avval status_code yoki raise_for_status().
⚠️ timeout yo'qtimeout bermasangiz, server javob bermaganda dastur cheksiz kutishi mumkin. Har so'rovga timeout=... bering.
⚠️ API kalitini kodga yozishKod GitHub ga chiqsa, kalit ham chiqadi. os.environ yoki .env faylidan oling (u .gitignore da bo'lsin).
⚠️ Manzilni qo'lda yig'ishurl + "?kategoriya=" + kat maxsus belgilarda buziladi. params={...} ishlating.
⚠️ Hamma xatoni bitta except bilan yutishexcept: pass xatoni yashiradi. Timeout, ConnectionError, HTTPError ni alohida ushlab, foydalanuvchiga aniq sabab ayting.
⚠️ Hammasini qayta so'rashO'zgarmaydigan ma'lumotni har safar so'ramang — keshlang. Aks holda dastur sekin, server yuklangan, ba'zan so'rov limiti tugaydi.
⚠️ O'quv API va haqiqiy internetBu darsda faqat https://api.xorazm-market.uz ishlaydi. Haqiqiy API (masalan, ob-havo xizmati) bilan ishlaganda ularning hujjatlarini o'qing: manzillar, kalitlar va so'rov limiti farq qiladi.
Maslahat: Yangi API bilan tanishganda avval print(r.status_code) va print(r.json()) qiling — javobning haqiqiy shaklini ko'rib, keyin kod yozing.

Qo'shimcha topshiriq

🎁 Bonus: Session. Haqiqiy requests da bir xil serverga ko'p so'rov yuborsangiz, s = requests.Session() yarating va s.get(...) ishlating: ulanish qayta ishlatiladi (tezroq), umumiy sarlavhalar (s.headers.update({...})) bir marta o'rnatiladi. 19-topshiriqdagi ApiMijoz ni shunga moslab yozib ko'ring.

Uyga vazifa

  1. Mahsulotlar jadvali. Hamma mahsulotni olib, narx bo'yicha tartiblab chiroyli jadval ko'rinishida chiqaring (23-dars f"{nom:<10}{narx:>8}" formatlari).
  2. Buyurtma dasturi. Foydalanuvchidan mahsulot id va sonini so'rab, buyurtma yuboring. Xatolarni (omborda yo'q, mahsulot topilmadi) tushunarli matn bilan ko'rsating.
  3. Kesh vaqti. 15-topshiriqdagi keshga "muddati" qo'shing: 60 soniyadan eski natija qayta so'ralsin (time.time()).
  4. Kurs tarixi. 20-topshiriqni kengaytiring: har chaqiruvda kursni tarix.csv ga sana bilan qo'shib borsin.
  5. Haqiqiy kompyuterda. Python ni kompyuteringizga o'rnatib (32-dars), pip install requests qiling va ochiq API (masalan, davlatlar yoki ob-havo ma'lumotlari) bilan shu darsdagi kodni sinab ko'ring.

Mini-test (8 ta savol)

1. HTTP holat kodi 404 nimani bildiradi?
404 — Not Found: so'ralgan narsa (manzil yoki yozuv) topilmadi.
2. Serverga yangi ma'lumot yuborish uchun odatda qaysi usul ishlatiladi?
GET ma'lumot oladi, POST esa yangi narsa yaratish uchun ma'lumot yuboradi.
3. requests.get(url, params={"a": 1}) nima qiladi?
params so'rov parametrlarini manzil oxiriga ?kalit=qiymat ko'rinishida qo'shadi.
4. raise_for_status() nima qiladi?
Xato holatlarida (4xx, 5xx) istisno ko'taradi — xatoni jim o'tkazib yubormaslik uchun.
5. timeout=1 nima uchun kerak?
timeout dasturni cheksiz kutishdan saqlaydi.
6. API kalitini qayerda saqlash to'g'ri?
Maxfiy kalit kodda bo'lmasligi kerak; os.environ orqali olinadi.
7. Bir xil so'rovni qayta yubormaslik uchun natijani lug'atda saqlash nima deyiladi?
Kesh — avval olingan natijani saqlab, takror so'rovsiz qayta ishlatish.
8. Bu kursda requests.get("https://google.com") nima beradi?
Brauzerdagi o'quv muhitida faqat api.xorazm-market.uz ishlaydi; boshqa manzillarda ConnectionError.
