Funksiyalar

Siz hozirgacha print(), len(), sum() kabi tayyor funksiyalardan foydalandingiz. Endi o'z funksiyalaringizni yozasiz. Funksiya — nom berilgan kod bo'lagi: uni bir marta yozasiz va xohlagancha chaqirasiz. Bu darsdan keyin kodingiz qisqa, tartibli va qayta ishlatiladigan bo'ladi.

⏱ ~3 soat🎯 def, parametr, return, standart qiymat, nomli argument, docstring🧩 20 topshiriq + mini-loyiha
40 daq nazariya100 daq 20 ta topshiriq30 daq mini-loyiha10 daq test

Darsning maqsadi

1
Funksiya yaratish — def bilan funksiya yozish va uni nomi orqali chaqirish.
2
Parametr va argument — funksiyaga ma'lumot berish: parametr — qavs ichidagi nom, argument — chaqirilganda beriladigan qiymat.
3
return va print farqi — natijani qaytarish va ekranga chiqarish o'rtasidagi farqni tushunish, None qayerdan chiqishini bilish.
4
Standart qiymat va nomli argument — foiz=10 kabi standart qiymat berish va f(yosh=15) ko'rinishida chaqirish.
5
Bir nechta qiymat qaytarish — return a, b bilan tuple qaytarish va uni x, y = f() bilan ochish.
6
Toza dastur tuzilishi — docstring yozish, bir funksiyadan boshqasini chaqirish va if __name__ == "__main__": bloki.

  • Xato bo'lsa, terminalda xato qatori va tushuntirish chiqadi. Xato topilgan qator oynada qizil bo'ladi.
  • ✔ Tekshirish tugmasi dasturingizni bir necha xil ma'lumot bilan sinab, har bir talabni alohida ✅ yoki ❌ bilan ko'rsatadi.

return va print farqi

💡 Asosiy fikr: print natijani ekranga yozadi, xolos. return esa natijani chaqirgan joyga qaytaradi: uni o'zgaruvchiga saqlash va keyin ishlatish mumkin.

🔹 Kalkulyator va doska

Kalkulyatorda hisoblasangiz, javobni yana boshqa hisobda ishlata olasiz — bu return. Javobni doskaga yozib qo'ysangiz, uni hamma ko'radi, lekin kalkulyator uni bilmaydi — bu print.

Standart qiymatlar va nomli argumentlar

💡 Asosiy fikr: Parametrga standart qiymat berish mumkin: argument berilmasa, shu qiymat olinadi. Chaqirganda argumentni nomi bilan ham berish mumkin.

🔹 Standart qiymat

Do'konda odatdagi chegirma 10%. Lekin bayramda 20% bo'lishi mumkin. Har safar 10 ni yozib o'tirmaslik uchun, uni standart qiymat qilamiz: foiz=10.

🔹 Nomli argumentlar

Argumentni nom=qiymat ko'rinishida bersangiz, tartib muhim emas. Bu kodni o'qishni ham osonlashtiradi.

📄 main.py

📌 Siz buni avval ham ko'rgansiz: print("a", "b", sep="-") dagi sep va end — print funksiyasining nomli argumentlari, ularning standart qiymati bor.

Docstring, funksiyadan funksiya va __main__

💡 Asosiy fikr: Yaxshi funksiya bitta ish qiladi va docstring bilan izohlanadi. Katta vazifa kichik funksiyalardan yig'iladi: bir funksiya boshqasini chaqiradi.

🔹 Docstring — funksiya "pasporti"

Funksiyaning birinchi qatoriga uch qo'shtirnoqli matn yoziladi. U funksiya nima qilishini aytadi. help(nom) uni ko'rsatadi.

📄 main.py

🔹 Funksiyadan funksiya chaqirish

Zavodda har sex o'z ishini qiladi: biri detal yasaydi, biri yig'adi. Dasturda ham shunday: kichik funksiyalarni yozib, katta funksiyada ularni ishlatasiz.

📄 main.py

Bunday kodni o'qish oson: if juftmi(x): qatorining o'zi nima bo'layotganini aytib turibdi.

🔹 if __name__ == "__main__":

Ko'pincha funksiyalardan keyin ularni sinab ko'radigan kod yoziladi. Uni shu blok ichiga joylash odat bo'lgan. Fayl o'zi ishga tushirilsa (▶), blok ichidagi kod bajariladi. Kursimizdagi avtomatik tekshirgich esa faqat funksiyalaringizni oladi va blokni ishlatmaydi.

Mini-test (8 ta savol)

1. Python'da funksiya qaysi kalit so'z bilan yaratiladi?
Funksiya def (define — aniqlash) bilan boshlanadi: def nom(parametrlar):.
2. def f(x): print(x * 2) bo'lsa, a = f(3) dan keyin a nimaga teng?
f ekranga 6 ni chiqaradi, lekin return yo'q. Shuning uchun funksiya None qaytaradi va a = None.
3. def f(a, b=5): return a + b bo'lsa, f(2) nima qaytaradi?
b berilmagani uchun standart qiymat 5 olinadi: 2 + 5 = 7.
4. Qaysi sarlavha xato (SyntaxError) beradi?
Standart qiymatli parametrdan keyin oddiy parametr kelishi mumkin emas. Standart qiymatlilar oxirida bo'ladi.
5. def g(): return 1, 2 bo'lsa, print(g()) nima chiqaradi?
Vergul bilan qaytarilgan qiymatlar bitta tuple bo'ladi: (1, 2).
6. Funksiyada return bajarilgandan keyin nima bo'ladi?
return qiymatni qaytaradi va funksiyadan darhol chiqadi. Undan keyingi qatorlar bajarilmaydi.
7. def t(ism, yosh): ... bo'lsa, qaysi chaqiruv to'g'ri?
Nomli argumentlarda tartib muhim emas. Oddiy argument nomlidan keyin kela olmaydi, argumentlar soni ham mos bo'lishi kerak.
8. Funksiya ichidagi uch qo'shtirnoqli birinchi matn nima deyiladi?
Docstring funksiya nima qilishini tushuntiradi. help(funksiya) uni ko'rsatadi.
