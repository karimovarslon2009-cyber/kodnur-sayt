Funksiyalar chuqurroq

O'tgan darsda siz funksiya yozishni o'rgandingiz. Endi funksiyalarning yashirin kuchlari bilan tanishasiz: istalgancha argument qabul qilish, bir qatorli lambda, sorted va max ga "qanday solishtirish"ni aytish, o'zini o'zi chaqiradigan funksiya (rekursiya). Ko'rinish sohasi: local va global

💡 Asosiy fikr: Funksiya ichida yaratilgan o'zgaruvchi faqat shu funksiya ichida yashaydi. Funksiya tugashi bilan u yo'qoladi.

🔹 Local va global

Funksiyadan tashqarida (faylning o'zida) yaratilgan o'zgaruvchi — global (umumiy). Uni hamma funksiyalar o'qiy oladi. Funksiya ichida yaratilgan o'zgaruvchi — local (mahalliy). Uni faqat o'sha funksiya ko'radi.

🏫 Maktabdagi kabi: maktab hovlisidagi e'lonni hamma o'qiydi (global). Sinf doskasidagi yozuvni esa faqat o'sha sinf ko'radi (local). Dars tugagach, doska tozalanadi.

Rekursiya: o'zini o'zi chaqiradigan funksiya

💡 Asosiy fikr: Rekursiya — funksiya o'zini o'zi chaqirishi. Har chaqiriqda masala kichrayadi, eng kichik holatda esa funksiya to'xtaydi.

🔹 Matryoshka kabi

Matryoshka qo'g'irchog'ini ochsangiz, ichida kichikrog'i chiqadi. Uni ochsangiz yana kichikrog'i. Eng kichigi ochilmaydi — shu yerda to'xtaysiz. Rekursiya ham shunday ishlaydi.

Har bir rekursiv funksiyada ikki qism bo'ladi:

  1. To'xtash sharti (base case): eng oddiy holat, javob tayyor.
  2. Rekursiv qadam: masalani kichikroq qilib, o'ziga topshirish.

🔹 Faktorial

5! = 5 * 4 * 3 * 2 * 1. Boshqacha aytsak: 5! = 5 * 4!. To'xtash sharti: 0! = 1.

📄 main.py

🧩 Qanday bajariladi?

Har chaqiriq o'z javobini kutib turadi. Eng ichkisi javob berganda, qolganlari teskari tartibda hisoblanadi.

faktorial(3)
= 3 * faktorial(2)
= 3 * (2 * faktorial(1))
= 3 * (2 * (1 * faktorial(0)))
= 3 * (2 * (1 * 1))
= 6
📄 main.py
⚠️ To'xtash sharti yo'q bo'lsaFunksiya o'zini cheksiz chaqiradi. Python taxminan 1000 qavatdan keyin to'xtatib, RecursionError beradi. Har rekursiv funksiyada avval to'xtash shartini yozing.
📄 main.py
Real loyihada: rekursiya ichma-ich tuzilmalar bilan ishlashda qulay: papka ichidagi papkalar, ichma-ich ro'yxatlar, oila daraxti, sayt menyulari.

💡 Asosiy fikr: Bu darsdagi xatolarning ko'pi ikki narsadan: funksiyani chaqirish va berish farqini unutish hamda rekursiyada to'xtash shartini unutish.
⚠️ UnboundLocalErrorhisob = hisob + 1 funksiya ichida, global hisob siz. Python hisob ni local deb hisoblaydi. Tuzatish: global yozing, yoki yaxshisi — qiymatni parametr bilan bering va return qiling.
⚠️ key ga funksiya natijasini berishsorted(sozlar, key=len()) — xato: len() chaqirildi. key ga funksiyaning o'zi beriladi: key=len.
⚠️ map/filter ni list ga o'ramaslikprint(map(str.upper, sozlar)) faqat <map object> chiqaradi. To'g'ri: print(list(map(str.upper, sozlar))).
⚠️ Rekursiyada to'xtash sharti yo'qdef f(n): return n * f(n - 1) — cheksiz chaqiriq va RecursionError. Avval if n == 0: return 1 yozing.
⚠️ Rekursiv natijani qaytarmaslikif ...: f(n - 1) deb yozib, return ni unutish. Natija None bo'lib qoladi. To'g'ri: return f(n - 1).
⚠️ O'zgaruvchan standart qiymatdef qosh(x, r=[]): — ro'yxat chaqiriqlar orasida umumiy bo'lib qoladi. To'g'ri: r=None va ichida if r is None: r = [].
⚠️ *args ni ro'yxat deb o'ylashdef f(*sonlar): sonlar.append(1) — xato: sonlar tuple, unga append yo'q. Kerak bo'lsa list(sonlar) qiling.
⚠️ lambda da return yozishlambda x: return x * 2 — SyntaxError. lambda ifoda natijasini o'zi qaytaradi: lambda x: x * 2.
Maslahat: rekursiv funksiya yozishdan oldin daftarga ikki narsani yozing: 1) eng oddiy holat va uning javobi; 2) masala qanday qilib bir qadam kichrayadi. Shundan keyin kod o'zi chiqadi.

Uyga vazifa

  1. Statistika. statistika(*sonlar) funksiyasini yozing: u (eng_kichik, eng_katta, ortacha) tuple qaytarsin. Son berilmasa (0, 0, 0) qaytarsin. Kamida 3 xil chaqiriq bilan sinang.
  2. Lug'at saralash. {"Ali": 85, "Lola": 92, "Sami": 78} lug'atini sorted(baholar.items(), key=lambda x: x[1], reverse=True) bilan saralab, 1. Lola - 92 ko'rinishida chiqaring.
  3. Rekursiv sanash. sana(matn, harf) funksiyasini sikl ishlatmasdan, rekursiya bilan yozing: matnda harf necha marta uchraydi. Maslahat: birinchi harfni tekshiring, qolganini matn[1:] bilan o'ziga bering.
  4. Fibonachchi. fib(n) ni rekursiv yozing (fib(0) = 0, fib(1) = 1). fib(30) ni hisoblab ko'ring: nega sekin ishlayotganini o'ylang va daftarga yozing.
  5. Funksiyalar menyusi. amallar = {"+": lambda a, b: a + b, "-": ..., "*": ..., "/": ...} lug'atini yarating. Foydalanuvchidan ikki son va amal belgisini input() bilan so'rab, amallar[belgi](a, b) bilan natijani chiqaring.

Mini-test (8 ta savol)

1. Funksiya ichida global o'zgaruvchiga yangi qiymat berish uchun nima yoziladi?
global kalit so'zi Python'ga bu nom funksiya ichida yangi local emas, balki umumiy o'zgaruvchi ekanini aytadi.
2. def f(*args): print(args) — f(1, 2, 3) nima chiqaradi?
*args hamma oddiy argumentlarni tuple ga yig'adi, shuning uchun (1, 2, 3) chiqadi.
3. **kwargs parametri argumentlarni qanday turga yig'adi?
Nomli argumentlar kalit-qiymat juftligi bo'lgani uchun lug'atga yig'iladi: {"ism": "Ali"}.
4. sorted(["anor", "olma", "qovun", "uzum"], key=len)[-1] nimaga teng?
Uzunlik bo'yicha saralanganda eng uzun so'z ("qovun", 5 harf) oxirida turadi.
5. list(map(lambda x: x * 2, [1, 2, 3])) natijasi qanday?
map har elementga lambda ni qo'llaydi: 1*2, 2*2, 3*2. list() natijani ro'yxatga aylantiradi.
6. Rekursiv funksiyada to'xtash sharti bo'lmasa nima bo'ladi?
Funksiya o'zini cheksiz chaqiradi. Python chuqurlik chegarasiga yetgach RecursionError beradi.
7. def qosh(x, r=[]): r.append(x); return r — qosh(1) dan keyin qosh(2) nima qaytaradi?
Standart qiymat [] bir marta yaratiladi va chaqiriqlar orasida umumiy bo'ladi, shuning uchun 1 ham saqlanib qolgan.
8. Qaysi yozuv to'g'ri lambda?
lambda shakli: lambda parametrlar: ifoda. return yozilmaydi, ifoda natijasi o'zi qaytadi.
