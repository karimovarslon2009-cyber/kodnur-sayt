Comprehension'lar va ma'lumotni qayta ishlash

Siz allaqachon for va append bilan yangi ro'yxat yasashni bilasiz. Bu ish uchun odatda 3–4 qator kerak bo'ladi. Python'da buni bitta qatorda yozish usuli bor: comprehension. Bu darsda ro'yxat, lug'at va to'plam comprehension'larini, hamda any, all va sum(... for ...) bilan ma'lumotni tez qayta ishlashni o'rganasiz.

⏱ ~3 soat🎯 [x for x in ...], if filtr, a if ... else b, {k: v for ...}, {x for ...}, ichma-ich, any, all, sum(... for ...)🧩 20 topshiriq + mini-loyiha
40 daq nazariya100 daq 20 ta topshiriq30 daq mini-loyiha10 daq test

Darsning maqsadi

1
Ro'yxat comprehension — [ifoda for x in ketma_ketlik] bilan bitta qatorda yangi ro'yxat yasash.
2
Shart bilan — oxiridagi if bilan elementlarni saralab olish (filtr) va boshidagi a if shart else b bilan qiymatni tanlash.
3
Lug'at va to'plam comprehension — {kalit: qiymat for ...} va {x for ...} yozish.
4
Ichma-ich comprehension — jadvalni tekislash, ikki for bilan juftliklar yasash va jadvalni transponirlash.
5
any, all, sum — any(), all() va sum(x for x in ...) bilan bitta qatorda tekshirish va hisoblash.
6
To'g'ri tanlov — qachon comprehension qulay, qachon oddiy sikl tushunarliroq ekanini bilish.

Bugungi yangi sintaksis

[x * x for x in sonlar][x for x in sonlar if x > 0][x if x > 0 else 0 for x in sonlar]{ism: len(ism) for ism in ismlar}{s[0] for s in sozlar}[x for qator in jadval for x in qator]any(b == 5 for b in baholar)all(b >= 3 for b in baholar)sum(x * x for x in sonlar)

Tez-tez uchraydigan xatolar

💡 Asosiy fikr: Comprehension xatolarining ko'pi uch joyda: shart qayerda turishi, qavs turi va nomlar mosligi.
⚠️ else filtrda[x for x in r if x > 0 else 0] → SyntaxError. else kerak bo'lsa, shartni oldinga o'tkazing: [x if x > 0 else 0 for x in r].
⚠️ Nomlar mos emas[son * 2 for x in sonlar] → NameError: name 'son' is not defined. Ifodada for dagi nomni ishlating: [x * 2 for x in sonlar].
⚠️ Qavs turi{x for x in r} — to'plam, [x for x in r] — ro'yxat. To'plamda tartib va takror yo'q, indeks ham ishlamaydi. Kerakli natija turiga qarab qavs tanlang.
⚠️ Lug'atda kalit takrorlanishi{baho: ism for ism, baho in juftlar} — bir xil baholi o'quvchilardan faqat oxirgisi qoladi. Kalit sifatida takrorlanmaydigan qiymatni oling: {ism: baho ...}.
⚠️ for lar tartibi[x for x in qator for qator in jadval] → NameError, chunki qator hali yo'q. Tashqi sikl birinchi yoziladi: [x for qator in jadval for x in qator].
⚠️ Natijani saqlamaslik[x * 2 for x in sonlar] deb yozib, keyin print(sonlar) — eski ro'yxat chiqadi. Comprehension asl ro'yxatni o'zgartirmaydi: sonlar = [x * 2 for x in sonlar].
⚠️ Faqat print uchun comprehension[print(x) for x in r] keraksiz None lar ro'yxatini yasaydi. Chiqarish uchun oddiy for yozing.
Maslahat: comprehension ishlamasa, uni oddiy for + append ko'rinishida yozib ko'ring. Sikl to'g'ri ishlasa, uni qaytadan bitta qatorga yig'ish oson.

  3. Sinf baholari. 5 ta o'quvchining ismi va bahosini kiriting. Lug'at comprehension bilan faqat 4 va 5 olganlar lug'atini yasang. all bilan hamma o'tganini tekshiring.
  4. Matn tahlili. Sevimli qo'shig'ingizdan bir band yozing. To'plam comprehension bilan har xil so'zlarni (kichik harfda) toping va sum(len(s) for s in ...) bilan jami harflar sonini hisoblang.
  5. Qayta yozish. Avvalgi darslardagi o'z kodingizdan for + append bor 2 ta joyni toping va comprehension'ga aylantiring. Natija o'zgarmaganini tekshiring.

Mini-test (8 ta savol)

1. [x * 2 for x in [1, 2, 3]] nima qaytaradi?
Har bir element 2 ga ko'paytiriladi va yangi ro'yxatga yoziladi.
2. [x for x in [5, -1, 0, 3] if x > 0] natijasi qaysi?
Oxiridagi if — filtr. Faqat 0 dan katta sonlar qoladi: 5 va 3.
3. Qaysi yozuv SyntaxError beradi?
Oxiridagi filtr if da else bo'lmaydi. else kerak bo'lsa, shart for dan oldin yoziladi.
4. {s[0] for s in ['olma', 'anor', 'olcha']} natijasi turi va uzunligi qanday?
Jingalak qavsda kalit: qiymat yo'q — bu to'plam. Birinchi harflar o, a, o — takrorsiz faqat 2 ta: o va a.
5. {n: n * n for n in range(3)} nima?
Lug'at comprehension: kalit n, qiymat n * n. range(3) — 0, 1, 2.
6. [x for q in [[1, 2], [3]] for x in q] nima qaytaradi?
Ikki for: avval tashqi (q), keyin ichki (x). Natija — tekislangan ro'yxat.
7. baholar = [4, 5, 3] bo'lsa, all(b >= 4 for b in baholar) nima beradi?
all faqat hamma element shartga mos bo'lsa True beradi. 3 baho 4 dan kichik, shuning uchun False.
8. sum(1 for x in [2, 7, 4, 9] if x > 5) nechaga teng?
5 dan katta har bir element uchun 1 qo'shiladi. Bunday sonlar 7 va 9 — jami 2.
