1 000 elementli ro'yxatda ikkilik qidiruv necha qadam 🔮 Bashorat 🟢 Oson

Ikkilik qidiruv har qadamda oraliqni yarmiga qisqartiradi. 1 000 ta sondan oxirgisini topish uchun nechta qadam kerak?
🔮 Topshiriq:
  1. Kodni o'qing. U 1 dan 1000 gacha bo'lgan sonlar ichidan 1000 ni qidiradi.
  2. Har aylanishda qadam 1 ga oshadi.
  3. Ikki qator chiqadi: chiziqli va ikkilik qidiruv qadamlari. Ularni pastga yozing.

Maslahat: 1000 ni necha marta 2 ga bo'lsangiz 1 ga yetadi?

royxat = list(range(1, 1001))
x = 1000

chiziqli = 0
for son in royxat:
    chiziqli += 1
    if son == x:
        break

chap, ong = 0, len(royxat) - 1
qadam = 0
while chap <= ong:
    qadam += 1
    orta = (chap + ong) // 2
    if royxat[orta] == x:
        break
    elif royxat[orta] < x:
        chap = orta + 1
    else:
        ong = orta - 1

print("Chiziqli:", chiziqli)
print("Ikkilik:", qadam)

Tez-tez uchraydigan xatolar

💡 Asosiy fikr: Algoritmlardagi xatolarning ko'pi chegaralarda: indeks bittaga ko'p yoki kam, oraliq kichraymaydi, almashish noto'g'ri. Kodni kichik misolda qog'ozda bajarib ko'rish eng yaxshi davo.
⚠️ Ikkilik qidiruvda chap = ortachap = orta yoki ong = orta deb yozsangiz, oraliq kichraymay qolishi va sikl cheksiz aylanishi mumkin. To'g'risi: chap = orta + 1, ong = orta - 1.
⚠️ while chap < ongIkkilik qidiruvda < yozsangiz, oraliqda bitta element qolganda sikl to'xtaydi va u tekshirilmaydi. Natija: bor element "topilmadi". To'g'risi: while chap <= ong.
⚠️ Saralanmagan ro'yxatda ikkilik qidiruvikkilik([5, 1, 9, 3], 3) noto'g'ri javob beradi. Ikkilik qidiruvdan oldin ro'yxat saralangan bo'lishi shart.
⚠️ IndexError: a[j + 1]Pufakchali saralashda for j in range(n - i) yozilsa, a[j + 1] ro'yxatdan chiqib ketadi. To'g'risi: range(n - 1 - i).
⚠️ Ikki qatorli almashisha[j] = a[j + 1] va a[j + 1] = a[j] — birinchi qatordan keyin eski qiymat yo'qoladi. To'g'risi: a[j], a[j + 1] = a[j + 1], a[j].
⚠️ return sikl ichidareturn -1 ni sikl ichida, else ga yozsangiz, funksiya birinchi elementdan keyinoq to'xtaydi. "Topilmadi" degan javob faqat sikl tugagandan keyin beriladi.
⚠️ Sikl ichida in yoki countfor x in a: if a.count(x) > 1 — ko'rinishidan bitta sikl, aslida O(n²): count ham butun ro'yxatni ko'radi. Lug'at yoki set ishlating.
Maslahat: algoritmni yozib bo'lgach, uni chekka holatlarda sinang: bo'sh ro'yxat, bitta element, izlangan element birinchi yoki oxirgi, takroriy qiymatlar. Ko'p xato aynan shu yerda chiqadi.

Mini-test (8 ta savol)

1. Ikkilik qidiruvning asosiy sharti qaysi?
Ikkilik qidiruv o'rtadagi elementga qarab yarmini tashlaydi. Bu faqat saralangan ro'yxatda to'g'ri ishlaydi.
2. 1 000 000 elementli saralangan ro'yxatda ikkilik qidiruv ko'pi bilan taxminan necha qadam qiladi?
Har qadamda oraliq yarmiga kamayadi: 2²⁰ ≈ 1 000 000. Shuning uchun taxminan 20 qadam yetadi.
3. Sikl ichida sikl bo'lgan kodning murakkabligi odatda qanday?
Tashqi sikl n marta, har birida ichki sikl n marta: jami n × n = n² qadam.
4. Quyidagi kod nima chiqaradi?<br><code>a = [3, 1, 2]<br>a[0], a[1] = a[1], a[0]<br>print(a)</code>
Python o'ng tomondagi ikkala qiymatni avval oladi, keyin bir vaqtda yozadi. Natijada 3 va 1 joy almashadi.
5. x in set amalining murakkabligi qanday?
set elementni xesh orqali to'g'ridan-to'g'ri topadi. Ro'yxat uzunligiga bog'liq emas.
6. Qaysi saralash ro'yxat deyarli saralangan bo'lsa eng tez ishlaydi?
Qo'yish saralashida element o'z joyida tursa, ichki while sikli darhol to'xtaydi. Saralangan ro'yxatda bu O(n).
7. Ikkilik qidiruvda royxat[orta] &lt; x bo'lsa, nima qilinadi?
x o'ng yarmida turibdi. orta allaqachon tekshirilgan, shuning uchun yangi oraliq orta + 1 dan boshlanadi.
8. time.perf_counter() nima uchun ishlatiladi?
Kod oldidan va keyin perf_counter() ni chaqirib, ayirmasini hisoblaysiz: bu kod ishlagan vaqt (soniyalarda).
