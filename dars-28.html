Type hints va testlash

Dastur ishlayapti — lekin to'g'ri ishlayaptimi? Bugun ertaga o'zgartirsangiz, boshqa joy buzilmaganini qanday bilasiz? Bu darsda uchta narsani o'rganasiz: tur izohlari (funksiya nima oladi va nima qaytaradi), testlar (kodni avtomatik tekshirish) va logging (dastur nima qilayotganini yozib borish). Professional dasturchilar kod yozishdan ko'ra ko'proq vaqtni shu ishlarga sarflaydi.

TDD: avval test, keyin kod

💡 Asosiy fikr: TDD (test-driven development): 1) test yozing (u yiqiladi 🔴), 2) testni o'tkazadigan eng sodda kodni yozing (🟢), 3) kodni yaxshilang.

Misol: kabisami(yil) funksiyasi kerak. Avval qoidalarni testda yozamiz:

def test_kabisami():
    assert kabisami(2024) is True    # 4 ga bo'linadi
    assert kabisami(2023) is False
    assert kabisami(1900) is False   # 100 ga bo'linadi, lekin 400 ga emas
    assert kabisami(2000) is True    # 400 ga bo'linadi

PEP 8 va logging

💡 Asosiy fikr: PEP 8 — Python kodini yozish uslubi bo'yicha umumiy kelishuv. logging esa print dan yaxshiroq: darajalari bor va o'chirib-yoqish mumkin.

🔹 PEP 8 asoslari

  • Funksiya va o'zgaruvchi nomlari: kichik_harf_bilan (snake_case); sinflar: KatalogYozuvi; konstantalar: MAKS_SON.
  • Chekinish: 4 ta bo'shliq. Qator uzunligi: 79 belgigacha.
  • Operatorlar atrofida bo'shliq: a = b + 1; vergulden keyin: f(a, b).
  • Funksiyalar orasida 2 ta bo'sh qator.

Mini-test (8 ta savol)

1. def f(x: int) -> str: da -> str nimani bildiradi?
Strelkadan keyingi tur — funksiya qaytaradigan qiymat turi.
2. Python tur izohlariga to'g'ri kelmaydigan qiymat berilsa nima bo'ladi?
Izohlar maslahat. Ularni tekshirish uchun mypy yoki VS Code kabi vositalar kerak.
3. str | None izohi nimani bildiradi?
Bu "matn yoki None" degani: funksiya natija topa olmasa None qaytarishi mumkin.
4. assert 2 + 2 == 5 qilsak nima bo'ladi?
Shart yolg'on bo'lsa assert AssertionError ko'taradi.
5. unittest.TestCase da quyidagi metod nomlaridan qaysi biri test sifatida ishga tushadi?
unittest faqat "test" bilan boshlangan metodlarni topadi.
6. Xato ko'tarilishini tekshirish uchun unittest da nima ishlatiladi?
with self.assertRaises(ValueError): ... — blok ichida ValueError chiqsa test o'tadi.
7. TDD tartibi qaysi?
Avval kutilgan xatti-harakatni testda yozasiz, keyin uni o'tkazadigan kodni.
8. logging da WARNING qachon ishlatiladi?
WARNING — ehtiyot bo'lish kerak, lekin amal bajarilmoqda. ERROR esa amal bajarilmaganda.
